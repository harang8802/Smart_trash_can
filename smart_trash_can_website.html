스마트 쓰레기통

쓰레기를 감지하고, 일정 시간이 지나면 경고하는 스마트 환경 시스템

프로젝트 소개

스마트 쓰레기통은 적외선 장애물 감지 센서를 이용해 쓰레기나 장애물이 감지되는지 확인하고, 감지 상태가 일정 시간 지속되면 LED와 부저로 알리는 장치입니다. 카메라 제어 핀을 통해 외부 카메라 장치에 신호를 보낼 수 있도록 설계했습니다.

감지적외선 장애물 감지 센서
경고LED 점등 및 부저 작동
확장카메라 제어 신호 출력

작동 순서

1장애물 감지
센서가 LOW 신호를 출력하면 감지 상태로 판단합니다.
23초 확인
감지 상태가 3초 동안 유지되는지 확인합니다.
3경고 시작
LED가 켜지고 부저에서 1000Hz 소리가 납니다.
4카메라 신호
D7 핀에서 0.2초 동안 제어 신호를 출력합니다.
5초기화
감지가 끝나면 LED와 부저가 꺼지고 대기 상태로 돌아갑니다.

준비 부품 및 핀 연결

부품아두이노 UNO 연결
적외선 센서 OUTD2
부저 (+)D8
LED (+)D13
카메라 제어 신호D7
센서 VCC / GND5V / GND

주의: D7은 카메라 자체를 구동하는 출력이 아니라 외부 카메라 모듈이나 제어 회로에 전달하는 신호입니다. 실제 촬영에는 별도의 호환 카메라 장치와 제어 회로가 필요합니다.

아두이노 코드

아래 코드는 프로젝트에 사용한 전체 코드입니다. 버튼을 눌러 복사할 수 있습니다.

smart_trash_can.ino
// Smart Trash Can - Arduino UNO

const int sensorPin = 2;
const int buzzerPin = 8;
const int ledPin = 13;
const int cameraPin = 7;

const unsigned long warningDelay = 3000;
const unsigned long cameraPulseTime = 200;

unsigned long detectedTime = 0;
unsigned long cameraStartTime = 0;

bool detected = false;
bool warning = false;
bool cameraActive = false;

void setup() {
  pinMode(sensorPin, INPUT);
  pinMode(buzzerPin, OUTPUT);
  pinMode(ledPin, OUTPUT);
  pinMode(cameraPin, OUTPUT);

  digitalWrite(ledPin, LOW);
  digitalWrite(cameraPin, LOW);

  Serial.begin(9600);
  Serial.println("Smart Trash Can Ready");
}

void loop() {
  bool sensorState = (digitalRead(sensorPin) == LOW);

  if (sensorState) {
    if (!detected) {
      detected = true;
      detectedTime = millis();
      Serial.println("Litter detected");
    }

    if (!warning &&
        millis() - detectedTime >= warningDelay) {
      warning = true;

      digitalWrite(ledPin, HIGH);
      tone(buzzerPin, 1000);

      digitalWrite(cameraPin, HIGH);
      cameraStartTime = millis();
      cameraActive = true;

      Serial.println("VOICE: Please pick up the litter.");
    }
  } else {
    detected = false;
    warning = false;

    digitalWrite(ledPin, LOW);
    noTone(buzzerPin);
  }

  if (cameraActive &&
      millis() - cameraStartTime >= cameraPulseTime) {
    digitalWrite(cameraPin, LOW);
    cameraActive = false;
  }
}

작동 시 참고 사항

  • 센서가 장애물 감지 시 LOW를 출력하는 설정을 기준으로 작성했습니다. 센서 모델에 따라 HIGH/LOW 동작이 다를 수 있습니다.
  • 시리얼 모니터에 출력되는 “VOICE” 문구는 실제 음성이 아니라 문자 메시지입니다. 음성 안내를 구현하려면 음성 재생 모듈이 추가로 필요합니다.
  • 카메라 제어 신호는 0.2초 동안 출력되며, 카메라 모듈의 입력 사양에 맞는 연결 회로가 필요합니다.
